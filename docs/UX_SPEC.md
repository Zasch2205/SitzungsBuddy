# UX Spezifikation (MVP)

## Operator-Modus

- Fokus auf Kontrolle und Fehlertoleranz
- Sichtbar: OnAir-Status, Gesamtzeit, Countdown, nächste Punkte

## Interaktionen

- `Space`: nächster aktiver Tagesordnungspunkt
- `H`: selektierten zukünftigen Punkt auf `Halt`
- Reorder für zukünftige Punkte
- `OnAir`-Toggle startet/stoppt Live-Session

## Beamer-Modus

- read-only und minimal
- zeigt aktuellen TOP, Titel und Restzeit
- keine internen Kontroll-Elemente
